# Versioning Philosophy

Sipier's versioning system is designed to communicate the scale and purpose of each release.

The general structure is:

```text
vMAJOR.MINOR.PATCH
```

Within the Sipier project:

```text
v1.0.0
```

represents a major application update.

```text
v0.1.0
```

represents a normal feature update.

```text
v0.0.1
```

represents a small bug fix or patch update.

The `BetaTesting` label identifies releases that are still undergoing active testing.

For example:

```text
v1.0.0 BetaTesting
```

indicates that the release is a major milestone but is still in the BetaTesting stage.
